🛠 단계 1: 패키지 설치 및 환경 준비
DNS 서버 운영에 필요한 핵심 패키지 3종 세트를 설치합니다.

🛠 단계 2: 네임 서버 메인 설정 (/etc/named.conf)
외부 클라이언트가 접속할 수 있도록 보안 설정을 해제합니다.

[수정 내용]

listen-on port 53 { any; };  (기존 127.0.0.1에서 변경)

allow-query { any; };       (기존 localhost에서 변경)

도메인 이름과 IP를 매칭하는 장부를 만듭니다.

위치: /var/named/thisislinux.com.db

현상: gedit /etc/resolv.conf 수정 시 저장 불가 (Read-only).

❌ 에러 3: 스냅샷 복구 후 서비스 마비
현상: 잘 되던 서비스가 갑자기 Directory not found 에러 발생.

원인: 강의 종료 후 가상머신을 이전 스냅샷으로 되돌려 패키지와 설정이 모두 삭제됨.

해결: 패키지 재설치(dnf install)부터 설정 파일(named.conf) 수정을 처음부터 다시 진행함.

4. 최종 확인 결과

DNS 쿼리 테스트: nslookup www.thisislinux.com -> 성공 (이름 풀이 정상)

도메인 접속 테스트: http://www.thisislinux.com -> 성공

5. 오늘의 교훈
스냅샷 주의: 리눅스 실습 시 스냅샷 시점을 정확히 관리하지 않으면 공들인 설정이 한순간에 날아갈 수 있다.

세미콜론(;)의 중요성: named.conf 설정 시 문장 끝에 ;를 빠뜨리면 서비스가 시작되지 않으므로 주의해야 한다.

권한 확인: 시스템 설정 파일을 건드릴 때는 항상 root 권한인지 확인하자.
