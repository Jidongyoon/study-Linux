# 🌐 2026년 2월 4일 네트워크 기초 및 참조 모델 학습 기록

## 1. 네트워크 프로토콜 (Network Protocol)
컴퓨터나 네트워크 장비가 서로 통신하기 위해 지켜야 하는 **약속이나 규칙**.
* 대표 예시: HTTP(웹), FTP(파일 전송), TCP/UDP(전송 방식) 등.

---

## 2. 네트워크 참조 모델 (OSI 7계층 & TCP/IP)
데이터가 전달되는 과정을 단계별로 표준화한 모델.

### OSI 7계층 (Open Systems Interconnection)
1.  **물리(Physical)**: 비트 단위 전송 (케이블, 허브)
2.  **데이터 링크(Data Link)**: 물리적 주소(MAC) 기반 인접 노드 간 전송
3.  **네트워크(Network)**: 논리적 주소(IP) 기반 경로 제어(Routing)
4.  **전송(Transport)**: 종단 간 신뢰성 있는 전송 (TCP/UDP)
5.  **세션(Session)**: 통신 세션 유지
6.  **표현(Presentation)**: 데이터 암호화, 압축, 형식 변환
7.  **응용(Application)**: 사용자 인터페이스 (HTTP, DNS 등)

---

## 3. 캡슐화와 역캡슐화 (Encapsulation & Decapsulation)

### 📦 캡슐화 (Encapsulation) - 송신측
* 상위 계층에서 내려온 데이터에 각 계층의 **헤더(Header)**를 붙여 하위 계층으로 보내는 과정.
* 과정: 데이터 → 세그먼트(TCP) → 패킷(IP) → 프레임(Ethernet) → 비트

### 🔓 역캡슐화 (Decapsulation) - 수신측
* 하위 계층에서 올라온 데이터의 **헤더를 하나씩 제거**하며 상위 계층으로 전달하는 과정.
* 최종적으로 수신자는 순수한 데이터를 확인하게 됨.

---

## 💡 핵심 정리
- **프로토콜**은 통신을 위한 규칙이다.
- **OSI 7계층**은 통신 과정을 7단계로 나눈 표준 모델이다.
- 데이터를 보낼 때는 헤더를 붙이는 **캡슐화**, 받을 때는 헤더를 떼는 **역캡슐화** 과정이 일어난다.
