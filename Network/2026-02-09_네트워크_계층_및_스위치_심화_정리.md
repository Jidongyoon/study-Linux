# 📅 2026-02-09 네트워크 계층 및 스위치(Switch) 핵심 원리 정리

## 1. 네트워크 참조 모델 및 계층별 기능
네트워크는 각 층마다 맡은 역할이 다르며, 오늘 중점적으로 다룬 곳은 L2와 L3입니다.

### [L2] 데이터 링크 계층 (Data Link Layer)
- **주소 체계**: **MAC 주소** (물리적 주소)
- **주요 기능**: 
  - 물리 계층을 통해 송수신되는 정보의 오류와 흐름을 관리.
  - 직접 연결된 인접 기기 간의 데이터 전송 보장.
- **대표 장비**: **L2 스위치**



### [L3] 네트워크 계층 (Network Layer)
- **주소 체계**: **IP 주소** (논리적 주소)
- **주요 기능**: 
  - **라우팅(Routing)**: 목적지까지 가장 안전하고 빠른 경로를 선택.
  - 서로 다른 네트워크 간의 데이터 패킷 전송(종단 간 통신).
- **대표 장비**: **라우터**, L3 스위치, 공유기

---

## 2. 네트워크 스위치(Switch)의 핵심 동작
스위치는 **MAC 주소 테이블**을 스스로 만들고 관리하며 데이터를 처리합니다.

### 💡 스위치의 5대 프로세스
1. **Learning (학습)**: 프레임이 들어오면 출발지 MAC 주소를 보고 해당 포트 번호를 테이블에 저장.
2. **Flooding (플러딩)**: 목적지 주소가 테이블에 없을 때, 들어온 포트를 제외한 모든 포트로 데이터를 뿌림.
3. **Forwarding (포워딩)**: 목적지 주소가 테이블에 있을 때, 해당 포트로만 정확히 전달.
4. **Filtering (필터링)**: 다른 포트로 데이터가 나가지 않게 차단하여 충돌(Collision) 방지 및 보안 유지.
5. **Aging (에이징)**: 일정 시간 통신이 없는 MAC 주소를 테이블에서 지워 효율성 유지.



---

## 3. 스위칭 데이터 전송 방식 (Switching Methods)
스위치가 데이터를 검사하는 정도에 따라 세 가지로 나뉩니다.
- **Store and Forward**: 전체 프레임을 다 받고 에러 체크(CRC) 후 전송 (가장 신뢰성 높음).
- **Cut-Through**: 목적지 주소만 확인하면 즉시 전송 (가장 빠름).
- **Fragment-Free**: 에러가 잦은 앞부분 64바이트만 확인하고 전송 (중간 형태).

---

## 4. 네트워크 진단 실무 명령어
- `ip addr`: 내 IP 및 인터페이스 상태 확인
- `nmtui` / `nmcli`: 네트워크 설정 관리 (IP, Gateway, DNS 등)
- `ping`: 상대 서버와 통신이 되는지 확인 (ICMP)
- `traceroute`: 목적지까지 거치는 경로(라우터) 추적
