# 🌐 01. 네트워크 거시적으로 알아보기
> **학습일**: 2026-01-31 (Sat)
> **주요 내용**: 네트워크를 이루는 4가지 핵심 구성 요소 이해

---

## 1. 호스트 (Host)
네트워크의 가장 가장자리에 위치하며, 데이터를 **생성**하거나 **최종적으로 소비**하는 장치입니다.
- **역할**: 네트워크에 연결된 끝단(End-point) 장치.
- **분류**:
  - **클라이언트 (Client)**: 서비스를 요청하는 호스트 (예: 내 WinClient 가상머신, 스마트폰).
  - **서버 (Server)**: 서비스를 제공하는 호스트 (예: 내가 설정한 Server(B), 구글 서버).
- **오늘의 실습 연결**: 아까 설치한 **Server(B)**와 **WinClient**가 각각 서비스 제공자와 요청자 역할을 하는 대표적인 '호스트'입니다.

## 2. 네트워크 장비 (Network Intermediate Device)
호스트와 호스트 사이에서 데이터를 전달하고 경로를 결정해 주는 장치입니다.
- **핵심 장비**:
  - **스위치 (Switch)**: 같은 네트워크 내의 호스트들을 연결하고 데이터를 전달.
  - **라우터 (Router)**: 서로 다른 네트워크를 연결하고 데이터의 최적 경로를 결정.
- **오늘의 실습 연결**: 우리가 사용하는 **VMware의 가상 스위치**가 내부적으로 호스트들을 연결해 주고 있습니다.

## 3. 통신 매체 (Transmission Media)
호스트와 네트워크 장비를 물리적으로 연결하여 데이터가 이동하는 '길'입니다.
- **유선 매체**: 트위스티드 페어 케이블(랜선), 광섬유 케이블 등.
- **무선 매체**: Wi-Fi, 블루투스, 5G 등.
- **오늘의 실습 연결**: 실제 랜선은 아니지만, VMware 설정에서 체크했던 **Virtual Network Adapter**가 가상적인 통신 매체 역할을 수행합니다.

## 4. 메시지 (Message)
네트워크를 통해 실제로 주고받는 '데이터' 그 자체입니다.
- **형태**: 웹 페이지 요청, 이미지 파일, 이메일, 동영상 스트리밍 데이터 등.
- **특징**: 네트워크를 흐를 때는 아주 작은 단위(패킷 등)로 쪼개져서 이동합니다.
- **오늘의 실습 연결**: `dnf install`을 칠 때 서버로 날아가는 요청이나, 내가 너(Gemini)와 주고받는 이 채팅 내용이 모두 메시지입니다.

---

### 📝 핵심 요약 (거시적 관점)
네트워크란, **호스트**들이 **통신 매체**를 통해 **네트워크 장비**에 연결되어 서로 **메시지**를 주고받는 유기적인 체계이다.
