# LG Twins Fan Page Project

## 📌 프로젝트 소개

이 프로젝트는 **LG 트윈스 팬을 위한 웹 서비스**를 직접 구축하고 운영하는 것을 목표로 합니다.

단순히 웹 페이지를 만드는 것에 그치지 않고, 실제 운영 환경을 고려하여 서버 구축부터 배포, 운영, 트러블슈팅까지 전 과정을 경험하는 것을 목표로 합니다.

---

# 🎯 프로젝트 목표

* Linux 기반 서버 운영
* Git/GitHub를 활용한 형상 관리
* Nginx를 이용한 웹 서비스 운영
* 웹 애플리케이션 배포
* 로그 분석 및 장애 대응
* Docker 기반 컨테이너 환경 구축
* AWS 클라우드 배포(추후)
* 운영 경험 및 트러블슈팅 기록

---

# 🛠 개발 환경

* OS : Rocky Linux 9
* Virtualization : VMware Workstation Pro
* Web Server : Nginx
* Version Control : Git / GitHub

---

# 📚 진행 방식

프로젝트를 진행하면서 아래 내용을 모두 기록합니다.

* 서버 구축 과정
* 환경 설정
* 설치 과정
* 문제 해결 과정(트러블슈팅)
* 운영하면서 발생한 이슈
* 성능 개선 과정

모든 과정은 GitHub Commit과 Markdown 문서로 관리합니다.
