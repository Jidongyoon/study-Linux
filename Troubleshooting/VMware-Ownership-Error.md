# 🛠️ 트러블슈팅: VMware 가상머신 소유권 오류 해결

## 1. 문제 상황
- **오류 메시지:** `Taking ownership of this virtual machine failed.`
- **현상:** 가상머신이 `Suspended` 상태에서 멈춘 뒤 다시 켜려고 하면 "이미 사용 중"이라며 실행되지 않음.

## 2. 원인 분석
- 가상머신 실행 시 중복 실행 방지를 위해 생성되는 **임시 잠금 폴더(.lck)**가 정상적으로 삭제되지 않아 발생함.

## 3. 해결 방법
1. 가상머신 저장 경로(`C:\Rocky9\Server\`)로 이동.
2. 폴더 내부의 `.lck` 확장자로 끝나는 모든 폴더를 삭제.
3. VMware 재실행 후 정상 작동 확인.

## 4. 교훈
- 가상머신을 끌 때는 가급적 **Shut Down**을 권장하며, 오류 발생 시 당황하지 말고 잠금 파일을 체크할 것.
