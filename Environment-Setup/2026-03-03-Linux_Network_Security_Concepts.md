Linux Network Infrastructure: DHCP, Proxy, and Firewall
본 문서는 리눅스 기반 네트워크 인프라 구축의 핵심 요소인 DHCP, Proxy 서버의 개념과 iptables를 이용한 방화벽 구축 원리를 정리합니다.

1. DHCP (Dynamic Host Configuration Protocol)
DHCP는 네트워크상의 단말기(Client)에 IP 주소, 서브넷 마스크, 기본 게이트웨이 등의 네트워크 정보를 자동으로 할당해 주는 프로토콜입니다.

주요 역할:

자동화: 수동 IP 설정의 번거로움 해소 및 관리 효율성 증대.

자원 절약: 사용 중이지 않은 IP를 회수하여 다른 단말에 재할당(Lease 시스템).

충돌 방지: 중복된 IP 할당으로 인한 네트워크 장애 예방.

작동 원리 (DORA 과정):

Discover: 클라이언트가 네트워크에 할당 가능한 DHCP 서버를 찾음.

Offer: 서버가 클라이언트에게 사용 가능한 IP 정보를 제안.

Request: 클라이언트가 제안받은 IP 사용을 서버에 요청.

Acknowledge (Ack): 서버가 최종 승인하며 임대 기간 등을 설정.

2. Proxy Server (프록시 서버)
Proxy는 클라이언트와 서버 사이에서 데이터를 중계하는 '대리인' 역할을 수행하는 서버입니다.

Forward Proxy: 내부망 클라이언트가 외부 인터넷에 접속할 때 거치는 서버. (보안, 속도 향상/캐싱)

Reverse Proxy: 외부 사용자가 내부 서버(웹 서버 등)에 접근할 때 거치는 서버. (부하 분산/Load Balancing, 보안 강화)

주요 기능:

보안: 실제 서버나 클라이언트의 IP를 숨김.

캐싱(Caching): 자주 요청되는 데이터를 저장하여 응답 속도 향상.

필터링: 특정 사이트 차단 또는 접근 제어 정책 적용.

3. Firewall (방화벽) 및 리눅스 보안 구축
방화벽은 미리 정의된 보안 규칙에 따라 들어오고 나가는 네트워크 트래픽을 모니터링하고 제어하는 보안 시스템입니다.

🔒 리눅스 방화벽의 구조
리눅스 커널 내부에는 Netfilter라는 패킷 처리 프레임워크가 있으며, 사용자는 도구를 통해 이를 제어합니다.

iptables: 오랫동안 표준으로 사용된 사용자 공간 도구. '표(Table)'와 '사슬(Chain)' 구조를 가짐.

firewalld: CentOS 7/RHEL 이후 기본으로 채택된 도구로, '영역(Zone)' 개념을 사용하여 관리가 용이함.

⚙️ iptables의 핵심 구성 요소
Tables (표):

Filter: 패킷의 허용/차단 여부 결정 (가장 기본).

NAT: 주소 변환(IP/Port Forwarding).

Chains (사슬):

INPUT: 서버로 들어오는 패킷.

OUTPUT: 서버에서 나가는 패킷.

FORWARD: 서버를 통과하여 다른 곳으로 전달되는 패킷 (Gateway 역할 시 중요).

PREROUTING: 라우팅 전(주소 변환 시) 적용.

POSTROUTING: 라우팅 후 적용.

4. 리눅스 방화벽 구축 핵심 기술 (NAT)
방화벽 서버를 통해 내부 사설망을 외부와 연결할 때 사용하는 핵심 기술입니다.

🌐 DNAT (Destination NAT) - 포트 포워딩
개념: 외부에서 방화벽의 공인 IP로 들어온 요청을 내부 사설망의 특정 서버 IP로 변경하여 전달하는 기술.

용도: 외부에서 내부 웹 서버나 DB 서버에 접속할 수 있도록 통로를 개방할 때 사용.

🌐 SNAT / MASQUERADE
개념: 내부 사설망의 클라이언트들이 외부 인터넷으로 나갈 때, 패킷의 출발지 주소를 방화벽의 공인 IP로 변환하는 기술.

용도: 사설 IP를 가진 여러 대의 PC가 하나의 공인 IP를 공유하여 인터넷을 사용할 때 사용.

💡 결론 및 요약
리눅스 기반 네트워크 보안 구축의 핵심은 정확한 IP 할당(DHCP), 중계 서버를 통한 보안(Proxy), 그리고 **커널 레벨에서의 패킷 제어(iptables/Firewall)**의 조합입니다. 특히 iptables의 NAT 기능을 활용하면 단일 공인 IP로도 복잡한 내부 사설망 서비스를 안전하게 외부로 노출하거나 보호할 수 있습니다.
