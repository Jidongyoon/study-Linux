# [Master Class] 쉘 스크립트 프로그래밍: 기초부터 심화까지 완벽 정리

## 1. 쉘 스크립트 변수 (Variables)
변수는 데이터를 담는 상자입니다. 쉘 스크립트에서는 타입(숫자, 문자 등)을 별도로 지정하지 않습니다.

* **정의**: `변수명=값` (등호 앞뒤에 공백이 없어야 함)
* **사용($)**: 변수 앞에 `$`를 붙여 상자 안의 값을 꺼냅니다.
* **실무 예시**:
    ```bash
    target_dir="/var/log"
    echo "현재 로그를 확인하는 디렉토리: $target_dir"
    ```

## 2. 조건문 (Conditional Statements)

### 2.1 if 문 (만약 ~라면)
특정 조건이 참인지 거짓인지에 따라 실행 경로를 결정합니다.


* **개념**: `[ ]` 안의 조건식을 평가하여 결과가 참이면 `then` 구간을 실행합니다.
* **실무 예시 (사용자 확인)**:
    ```bash
    if [ "$USER" != "root" ]; then
        echo "이 작업은 root 권한이 필요합니다."
        exit 1
    fi
    ```

### 2.2 case 문 (경우에 따라)
하나의 변수에 대해 여러 가지 가능성이 있을 때 사용하며, `if`보다 가독성이 훨씬 뛰어납니다.
* **개념**: 변수의 값과 일치하는 패턴을 찾아 해당 블록을 실행합니다.
* **실무 예시 (메뉴 선택)**:
    ```bash
    echo "1: 백업 시작, 2: 시스템 종료"
    read choice
    case $choice in
        1) tar -cvf backup.tar /home ;;
        2) shutdown -h now ;;
        *) echo "잘못된 선택입니다." ;;
    esac
    ```

## 3. 반복문 (Loop Structures)

### 3.1 for ~ in 문 (정해진 횟수만큼)
주어진 리스트의 개수만큼 반복합니다.


* **개념**: `in` 뒤에 오는 데이터들을 하나씩 변수에 대입하며 `do`와 `done` 사이를 실행합니다.
* **실무 예시 (일괄 권한 변경)**:
    ```bash
    for script in *.sh
    do
        chmod 755 $script
        echo "$script 파일에 실행 권한을 부여했습니다."
    done
    ```

### 3.2 while 문 (조건이 맞을 때까지)
조건이 참인 동안 무한히 반복합니다.
* **개념**: 루프가 시작될 때마다 조건을 체크하며, 조건이 거짓이 되면 탈출합니다.
* **실무 예시 (서비스 모니터링)**:
    ```bash
    while [ 1 ]  # 무한 루프
    do
        echo "서버 상태 감시 중... (Ctrl+C로 종료)"
        sleep 5
    done
    ```

## 4. 파라미터 변수와 shift (동적 인자 처리)

### 4.1 파라미터 변수 ($0, $1, $*)
스크립트 외부에서 던져주는 값을 받는 특수 변수입니다.


* **$0**: 스크립트 자기 자신의 이름
* **$1, $2...**: 첫 번째, 두 번째 인자
* **$#**: 전달된 인자의 총 개수

### 4.2 shift (파라미터 밀어내기)
* **개념**: 파라미터를 왼쪽으로 한 칸씩 이동시킵니다. `$2`가 `$1`이 되고, `$1`은 사라집니다.
* **실무 예시 (가변 인자 처리)**:
    ```bash
    # 실행 예: ./install.sh app1 app2 app3
    while [ "$1" != "" ]
    do
        echo "$1 설치를 시작합니다..."
        # 설치 로직 실행
        shift
    done
    ```

## 5. 사용자 정의 함수 (Functions)
자주 쓰는 코드를 재사용하기 위해 묶어둔 코드 블록입니다.

* **정의**: `함수이름() { ... }`
* **호출**: 스크립트 내에서 `함수이름`만 쓰면 실행됨.
* **실무 예시 (에러 메시지 공통화)**:
    ```bash
    error_exit() {
        echo "[ERROR] $1"
        exit 1
    }

    # 사용법
    [ -f config.conf ] || error_exit "설정 파일이 없습니다."
    ```
