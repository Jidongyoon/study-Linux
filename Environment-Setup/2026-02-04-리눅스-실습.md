# 🐧 2026년 2월 4일 리눅스 에디터 및 마운트 실습 기록

## 1. vi/vim 에디터 활용 실습
리눅스 환경에서 설정 파일 편집을 위한 표준 에디터 활용법 숙달.

### ⌨️ 주요 명령어 요약
* **모드 전환**: `i` (입력 모드), `Esc` (명령 모드)
* **저장 및 종료**: 
    * `:wq` : 저장 후 종료
    * `:q!` : 저장 없이 강제 종료 (수정 취소)
* **텍스트 편집 효율화**:
    * `yy` / `p` : 한 줄 복사 / 붙여넣기
    * `dd` : 한 줄 삭제 (잘라내기)
    * `u` : 마지막 작업 실행 취소 (Undo)
    * `gg` / `G` : 문서 최상단 / 최하단 이동

## 2. 스토리지 마운트(Mount) 실습
CD/DVD 및 USB와 같은 외부 장치를 리눅스 파일 시스템에 연결하는 프로세스 실습.

### 🛠️ 실습 단계
1.  **장치 인식 확인**: `lsblk` 또는 `fdisk -l`로 연결된 장치 이름 확인.
2.  **마운트 포인트 생성**: 장치를 연결할 빈 폴더 생성.
    * `mkdir /mnt/cdrom` 또는 `mkdir /mnt/usb`
3.  **마운트 실행**: 물리 장치와 디렉토리 연결.
    * `mount /dev/cdrom /mnt/cdrom`
4.  **장치 활용**: 마운트된 경로(`cd /mnt/cdrom`)로 이동하여 내부 데이터 확인.

### ⚠️ 중요: 마운트 해제(Unmount) 시 주의사항
* **오류 상황**: 마운트된 디렉토리 안(Busy 상태)에서 `umount` 실행 시 해제 불가.
* **해결 방법**: 반드시 **`cd ~`** 또는 **`cd ..`** 명령어를 사용하여 **해당 폴더를 벗어난 후** 해제를 실행해야 함.
    * 예: `cd ~` 입력 후 `umount /mnt/cdrom`

## 💡 오늘 학습 포인트
- 윈도우와 달리 리눅스는 장치 연결 후 수동 마운트 과정이 필수적임.
- 파일 편집 후 저장하는 습관과 장치 안전 제거(Unmount)의 올바른 순서를 익힘.
