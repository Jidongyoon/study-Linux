# 🐧 Linux 실무 기초: 사용자 관리 및 파일 시스템 권한 (2026-02-05)

오늘 실습은 리눅스 시스템의 뼈대인 사용자 관리와 파일의 보안(권한), 그리고 효율적인 파일 관리를 위한 링크 개념을 중점적으로 학습함. 원리를 이해하고 명령어를 사용하니 에러 없이 실습이 진행됨.

---

## 1. 사용자 및 그룹 관리
리눅스는 멀티 유저 시스템이므로 사용자와 그룹을 나누어 관리하는 것이 기본임.

### 주요 개념 및 명령어
* **`/etc/skel` (Skeleton):** 새로운 사용자 생성 시 홈 디렉토리에 자동으로 복사되는 **'기본 뼈대'** 파일 보관소. (예: `.bashrc`, `.profile` 등)
* **`cd` vs `cd /`**: 
    * `cd`: 현재 로그인한 사용자의 **홈 디렉토리(Home)**로 이동.
    * `cd /`: 시스템 최상위 **루트 디렉토리(Root)**로 이동.
* **사용자 생성/삭제**:
    * `useradd` / `adduser`: 사용자 계정 생성.
    * `userdel -r [사용자명]`: 사용자를 삭제할 때 홈 디렉토리까지 깔끔하게 제거함. (안 쓰면 찌꺼기 파일이 남음!)

---

## 2. 파일 허가권 (Permission)과 소유권 (Ownership)
누가 이 파일을 읽고, 쓰고, 실행할 수 있는지를 결정하는 핵심 보안 요소.

### 허가권 (Permission)
`ls -l` 명령어로 확인 시 `-rwxr-xr--` 같은 형태로 표시됨.
* **r (Read, 4):** 읽기
* **w (Write, 2):** 쓰기
* **x (Execute, 1):** 실행
* **권한 구조:** `[소유자(u)][그룹(g)][기타사용자(o)]` 순서로 3개씩 끊어서 해석.
    * *예: 755는 소유자(읽/쓰/실), 그룹(읽/실), 기타(읽/실)*

### 소유권 (Ownership) 변경
* **`chown` (Change Owner):** 파일의 소유자와 그룹을 변경.
    * `chown user1:group1 file.txt`
* **`chmod` (Change Mode):** 파일의 허가권을 변경.
    * `chmod 777 file.txt` (모든 권한 허용)

## 3. 링크 (Link): 하드 링크 vs 심볼릭 링크
파일을 가리키는 두 가지 방식의 차이점을 명확히 이해해야 함.

### 🔗 하드 링크 (Hard Link)
* **개념:** 원본 파일의 **데이터(inode)**를 직접 가리키는 복제본.
* **특징:**
    * 원본 파일을 삭제해도 하드 링크 파일은 그대로 남아서 데이터를 유지함.
    * 원본과 링크 파일이 같은 번호(inode)를 공유함.
    * 파일 크기가 원본과 동일함.

### 🔗 심볼릭 링크 (Symbolic Link / Soft Link)
* **개념:** 윈도우의 **'바로가기 아이콘'**과 같음. 원본 파일의 경로를 가리킴.
* **명령어:** `ln -s [원본] [링크명]`
* **특징:**
    * 원본 파일이 삭제되거나 이동하면 링크가 끊김 (사용 불가).
    * 원본과 다른 번호(inode)를 가짐.
    * 파일이나 디렉토리 모두에 만들 수 있어 실무에서 훨씬 자주 쓰임.
