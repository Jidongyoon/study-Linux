## ⌨️ 리눅스 기본 조작 및 효율적 환경 설정

### 1. 시스템 종료 및 재부팅 (Power Control)
* **`shutdown -h now`**: 지금 즉시 시스템 종료 (마치 전원을 끄듯 안전하게).
* **`reboot`** 또는 **`shutdown -r now`**: 시스템 재부팅.
* **학습 내용**: 리눅스는 다중 사용자 운영체제이므로, 종료 전 반드시 데이터를 저장하고 안전하게 종료 명령어를 사용하는 습관이 중요하다.

### 2. 가상 콘솔 (Virtual Console)
* **개념**: 하나의 모니터에서 여러 개의 터미널 창을 띄운 것처럼 사용하는 기능.
* **단축키**: `Ctrl` + `Alt` + `F2 ~ F6` (텍스트 모드), `Ctrl` + `Alt` + `F1` (GUI 모드).
* **실전 활용**: GUI가 응답하지 않을 때 TTY 콘솔로 진입하여 프로세스를 강제 종료하거나 상태를 점검하는 '비상구'로 활용함.

### 3. 런레벨(Runlevel)과 타겟(Target)
* **역사**: 과거 리눅스는 0~6번까지의 **런레벨** 숫자로 시스템 상태를 구분했음.
* **현재 (systemd)**: 숫자가 아닌 **Target** 명칭을 사용함.
  - `multi-user.target` (런레벨 3): 텍스트 모드.
  - `graphical.target` (런레벨 5): 그래픽 모드.
* **교훈**: `systemctl`을 통해 부팅 시 어떤 '목적지(Target)'로 갈지 정하는 것이 핵심.

### 4. 자동완성 (Tab Completion)
* **기능**: 명령어의 일부나 파일명의 일부만 치고 **`Tab`** 키를 누르면 시스템이 나머지를 완성해줌.
* **효과**: 오타 방지 및 작업 속도 비약적 향상.
* **꿀팁**: 탭을 두 번 연타하면 현재 입력어로 시작하는 모든 명령어 목록을 보여줌.
