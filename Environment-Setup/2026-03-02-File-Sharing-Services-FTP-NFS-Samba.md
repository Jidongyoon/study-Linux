[2026-03-02] File Sharing Service Architectures: FTP, NFS, and Samba
오늘 학습은 리눅스 환경에서 다양한 프로토콜을 이용해 자원을 공유하는 서버 구축 기술을 다뤘습니다. 각 서비스의 특징과 적합한 활용 사례를 정리합니다.

1. FTP (File Transfer Protocol) 기반 서비스
FTP는 가장 고전적이고 대중적인 파일 전송 프로토콜입니다. 오늘 실습한 두 가지 서버는 철학이 다릅니다.

🐧 vsftpd (Very Secure FTP Daemon)
개념: 보안과 성능, 안정성을 최우선으로 설계된 리눅스 표준 FTP 서버입니다.

특징:

보안(Security)에 특화되어 설정이 매우 깐깐함.

대규모 트래픽 처리에 능하며 가벼움.

RHEL/Rocky Linux 계열에서 가장 많이 권장되는 기본 서버.

🦢 pure-ftpd
개념: '순수함(Pure)'이라는 이름답게 설정이 간결하고 유연한 FTP 서버입니다.

특징:

가상 사용자(Virtual User) 설정이 매우 쉬워 보안 관리에 유리함.

메모리 점유율이 낮고 성능이 뛰어남.

웹 호스팅 환경이나 소규모 서버에서 선호됨.

2. NFS (Network File System)
리눅스 간의 '운명 공동체'를 만드는 서비스입니다.

개념: 네트워크를 통해 다른 리눅스 서버의 디렉터리를 마치 내 로컬 하드디스크인 것처럼 연결(Mount)하여 사용하는 방식입니다.

핵심 특징:

리눅스/유닉스 친화적: 리눅스 서버끼리 데이터를 공유할 때 가장 빠르고 효율적임.

투명성: 사용자는 이 파일이 내 컴에 있는지 서버에 있는지 구분할 필요가 없음.

RPC(Remote Procedure Call) 기반 통신을 사용하여 데이터 전송 효율이 높음.

3. Samba (SMB/CIFS)
리눅스와 윈도우 사이의 '통역사' 역할을 하는 서비스입니다.

개념: 윈도우의 파일 공유 프로토콜인 **SMB(Server Message Block)**를 리눅스에서 구현한 서비스입니다.

핵심 특징:

이종 OS 간 공유: 윈도우 PC에서 리눅스 서버의 폴더를 '네트워크 드라이브'로 연결할 때 필수.

도메인 통합: 윈도우의 Active Directory(AD)와 연동하여 사용자 인증을 공유할 수 있음.

프린터 공유: 파일뿐만 아니라 프린터 자원 공유도 지원.

오늘 배운 서비스들은 모두 '파일 공유'라는 목적은 같으나, 네트워크 환경과 클라이언트의 OS에 따라 선택지가 달라진다. 엔지니어는 시스템 요구사항을 분석하여 가장 효율적이고 보안성이 높은 프로토콜을 선택할 수 있는 안목을 가져야 한다.
