# 📅 [202X-XX-XX] 학습 기록: Linux 네트워크 명령어 및 시스템 심화

## 1. 네트워크 관리 및 진단 명령어 (핵심!)
- **`ip addr`**: 네트워크 인터페이스의 IP 주소와 상태를 확인. (구 `ifconfig` 대체)
- **`nmtui`**: (Network Manager Text User Interface) 그래픽 없이 터미널에서 화살표로 간편하게 IP, 게이트웨이, DNS를 설정하는 도구.
- **`nmcli`**: 커맨드라인에서 네트워크 설정을 변경할 때 사용. (예: `nmcli device show`)
- **`ping [IP/도메인]`**: ICMP 프로토콜을 이용해 상대방 서버와 통신이 되는지 확인하는 가장 기본적인 도구.
- **`traceroute`**: 목적지까지 거치는 모든 라우터(게이트웨이) 경로를 추적하여 어디서 병목이 생기는지 확인.
- **`netstat -nr` 또는 `route -n`**: 현재 시스템의 라우팅 테이블(기본 게이트웨이 등)을 확인.

## 2. 프로세스 및 파이프라인 (Process & Pipe)
- **Pipe (`|`)**: 명령어의 출력을 다음 명령어의 입력으로 연결.
  - 예: `ps -ef | grep httpd` (실행 중인 프로세스 중 httpd만 골라보기)
- **`ps -ef` / `ps aux`**: 시스템의 모든 프로세스 리스트 상세 확인.
- **`kill -9 [PID]`**: 응답 없는 프로세스를 강제 종료.
- **`systemctl`**: 서비스(데몬) 관리.
  - `systemctl enable --now [서비스명]`: 부팅 시 자동 시작 설정과 동시에 현재 바로 실행.

## 3. SELinux (보안 커널)
- **`sestatus`**: SELinux의 현재 활성화 상태 및 정책 확인.
- **`setenforce 0`**: 임시로 `Permissive` 모드로 변경 (보안 정책은 무시하되 로그는 남김).
- **`setenforce 1`**: 다시 `Enforcing` 모드로 변경.
- **`/etc/selinux/config`**: 영구적으로 SELinux 모드를 변경할 때 수정하는 파일.

## 4. GRUB 부트로더 및 응급 복구
- **GRUB**: 부팅 메뉴를 제공하고 커널을 로드하는 장치.
- **응급 복구 절차 (Root 패스워드 재설정)**:
  1. 부팅 시 GRUB 메뉴에서 `e`키 입력.
  2. `linux`로 시작하는 라인 끝에 `rd.break` 추가 후 `Ctrl+X`.
  3. `mount -o remount,rw /sysroot` (쓰기 권한 부여).
  4. `chroot /sysroot` (루트 디렉토리 변경).
  5. `passwd root` (새 비밀번호 설정).
  6. `touch /.autorelabel` (SELinux 보안 컨텍스트 재설정 필수!).
  7. `exit` -> `reboot`.

## 5. 오늘의 네트워크 장비 철학
- **공유기**: 단순한 기계가 아니라 **DHCP**(IP 할당), **Gateway**(통로), **L2 Switch**(내부 연결), **L3 Router**(외부 길찾기) 기능이 집약된 핵심 장비.
- **스위칭**: MAC 주소 기반의 내부 통신.
- **라우팅**: IP 주소 기반의 외부(다른 네트워크) 통신.

---
### 💡 오늘의 메모
- 네트워크 설정 후에는 반드시 `nmcli connection up [장치명]` 또는 `systemctl restart NetworkManager`로 적용할 것.
- 응급 복구 시 `/.autorelabel` 과정을 빼먹으면 부팅 후 로그인이 안 될 수 있으니 주의!

## 📂 오늘 반드시 기억해야 할 주요 설정 파일 경로

### 1. 네트워크 관련 (Network)
- **/etc/hostname**: 서버의 이름을 설정하는 파일.
- **/etc/sysconfig/network-scripts/ifcfg-[장치명]**: 네트워크 인터페이스의 상세 설정(IP, 게이트웨이, DNS 등)이 저장되는 곳. (RHEL/CentOS 계열)
- **/etc/resolv.conf**: DNS 서버 주소(예: 8.8.8.8)가 저장되는 파일.
- **/etc/hosts**: IP 주소와 호스트명을 수동으로 매핑할 때 사용하는 파일. (DNS보다 우선순위 높음)

### 2. 서비스 및 자동화 (Cron & Service)
- **/etc/crontab**: 시스템 전체의 예약 작업 관리 파일.
- **/var/spool/cron/[사용자명]**: 일반 사용자가 `crontab -e`로 예약한 내용이 저장되는 실제 위치.
- **/usr/lib/systemd/system/**: 각 서비스(`sshd`, `httpd` 등)의 실행 방식이 정의된 유닛 파일들이 모여있는 곳.

### 3. 보안 및 사용자 (Security)
- **/etc/selinux/config**: SELinux의 모드(`Enforcing`, `Permissive`, `Disabled`)를 영구 설정하는 파일.
- **/etc/shadow**: 사용자 비밀번호가 암호화되어 저장되는 보안 파일. (응급 복구 시 중요)
- **/etc/sudoers**: 일반 사용자에게 `sudo` 권한을 부여할 때 수정하는 파일 (`visudo` 명령 사용 권장).

### 4. 부팅 및 시스템 (Boot & Filesystem)
- **/etc/default/grub**: GRUB 부트로더의 기본 설정(대기 시간, 커널 매개변수 등)을 관리하는 파일.
- **/boot/grub2/grub.cfg**: GRUB의 최종 설정 파일 (직접 수정하기보다 `grub2-mkconfig`로 생성함).
- **/etc/fstab**: 부팅 시 자동으로 마운트될 파티션 정보가 담긴 파일. (잘못 건드리면 부팅 안 됨!)

### ⚠️ 주의사항 (실무 팁)
- 설정 파일을 수정하기 전에는 반드시 **백업본**을 만드세요!
  - 예: `cp /etc/selinux/config /etc/selinux/config.bak`
- 네트워크 설정 변경 후에는 `nmcli connection reload` 또는 `systemctl restart NetworkManager`가 필수입니다.
