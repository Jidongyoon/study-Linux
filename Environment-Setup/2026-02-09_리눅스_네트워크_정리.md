# 📅 2026-02-09 리눅스 시스템 관리 및 네트워크 심화 정리

## 1. 네트워크 관리 및 진단 명령어
- **`ip addr`**: IP 주소 및 네트워크 인터페이스 상태 확인 (구 `ifconfig` 대체)
- **`nmtui`**: 터미널 기반의 텍스트 UI로 네트워크(IP, 게이트웨이, DNS 등)를 간편하게 설정
- **`nmcli`**: 커맨드라인에서 네트워크 장치와 연결을 직접 관리 (예: `nmcli device show`)
- **`ping [IP/도메인]`**: ICMP 패킷을 이용해 상대 서버와 통신이 가능한지 확인
- **`traceroute`**: 패킷이 목적지까지 거치는 모든 라우터(경로)를 추적하여 지연 구간 확인

## 2. 프로세스 및 서비스 관리
- **파이프 (`|`)**: 앞 명령어의 출력을 다음 명령어의 입력으로 전달 (예: `ps -ef | grep sshd`)
- **`ps -ef` / `ps aux`**: 실행 중인 모든 프로세스의 상세 정보 확인
- **`kill -9 [PID]`**: 응답하지 않는 프로세스를 강제 종료
- **`systemctl`**: 시스템 서비스(데몬) 관리
  - `start`, `stop`, `restart`, `status` 제어
  - `enable --now`: 부팅 시 자동 시작 설정과 현재 실행을 동시에 처리

## 3. SELinux (보안 강화 커널)
- **개념**: 관리자 권한도 제어하는 강력한 보안 정책 모듈
- **상태 확인**: `sestatus`, `getenforce`
- **모드 종류**:
  - `Enforcing`: 보안 정책 강제 차단
  - `Permissive`: 정책 위반 시 로그만 남기고 허용 (테스트용)
  - `Disabled`: 비활성화

## 4. 부트로더(GRUB) 및 응급 복구
- **GRUB**: 시스템 부팅 시 커널을 로드하는 관문
- **Root 패스워드 분실 시 복구 절차**:
  1. 부팅 시 GRUB 메뉴에서 `e` 입력
  2. 커널 라인 끝에 `rd.break` 추가 후 실행
  3. `mount -o remount,rw /sysroot` (쓰기 권한 마운트)
  4. `chroot /sysroot` -> `passwd` 명령으로 비밀번호 재설정
  5. `touch /.autorelabel` (SELinux 레이블 재설정 필수)
  6. 재부팅

## 📂 반드시 알아야 할 주요 설정 파일 경로
- **/etc/sysconfig/network-scripts/**: 네트워크 인터페이스 상세 설정 파일 위치
- **/etc/resolv.conf**: 사용 중인 DNS 서버 주소 설정
- **/etc/hosts**: IP와 호스트명 수동 매핑
- **/etc/selinux/config**: SELinux 모드 영구 설정
- **/etc/fstab**: 부팅 시 자동 마운트될 파티션 정보
- **/etc/default/grub**: GRUB 부트로더 기본 설정 파일

## 💡 오늘의 네트워크 장비 철학
- **공유기**: 단순 Wi-Fi 기계가 아니라 **DHCP**(IP할당), **Gateway**(통로), **Switch**(내부연결), **Router**(외부 길찾기) 기능이 모두 담긴 핵심 장치
- **스위칭**: MAC 주소 기반의 L2 통신
- **라우팅**: IP 주소 기반의 L3 통신
